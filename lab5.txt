sudo apt update
sudo apt install -y binwalk file binutils xxd

mkdir -p ~/firmware-lab
cd ~/firmware-lab
wget -O firmware.img.gz https://downloads.openwrt.org/releases/25.12.4/targets/x86/64/openwrt-25.12.4-x86-64-generic-squashfs-rootfs.img.gz

sha256sum firmware.img.gz

gzip -dk firmware.img.gz
mv firmware.img firmware.bin

file firmware.bin
sha256sum firmware.bin
strings -n 6 firmware.bin | head -n 50   //find readable strings
binwalk firmware.bin     //scan firmware
binwalk -e firmware.bin     //Extract embedded components
find _firmware.bin.extracted -maxdepth 3 -type f | head -n 50    //list files
find _firmware.bin.extracted -type f -exec file {} \; | head -n 30     //list file types



squashFS is a filesystem

result of find _firmware.bin.extracted -type f -exec file {} \; | head -n 30 
File	       -   Type reported
0.squashfs	 -    Squashfs filesystem, little endian, version 4.0, xz compressed, 6109442 bytes, 1290 inodes
sbin/procd, sbin/netifd, sbin/uci, sbin/init  -	ELF 64-bit LSB executable, x86-64, dynamically linked (compiled programs)
sbin/sysupgrade, sbin/firstboot, sbin/fw4	 - POSIX shell script, ASCII text executable (readable scripts)

overall final Findings:

Embedded filesystem: SquashFS, xz-compressed
Architecture: x86-64
Libraries: the programs use the musl C library (/lib/ld-musl-x86_64.so.1)
Contents: system programs, shell scripts and other router files

Note: the find ... -exec file {} \; | head command may print many terminated by signal 13 lines. They are harmless. They appear because head stops after 30 lines while find is still working. Add 2>/dev/null to hide them.

RESULT
Static firmware analysis was performed, and the embedded SquashFS filesystem and its components were identified and documented.
